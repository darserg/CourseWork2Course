# Практика
В этой части выполнена практическая часть работы по курсовой. 
## Инфраструктура
### Тестовая БД (заглушка)
`infrastructure/user_store.py` - реализация временной базы данных с сохраненинем всех данных в `users.json`.

`users.json` создаётся автоматически, хранит в себе данные в формате:

```json
{
  "users": {
    "email1": {
      "password_hash": string,
      "salt": string,
      "created_at": string,
      "is_verified": bool
    },
    "email2": {
      "password_hash": string,
      "salt": string,
      "created_at": string,
      "is_verified": bool
    }
  }
}
```

Хэширование происходит по алгоритму `sha256`, реализация через библиотеку `hashlib`.

### Основной код проекта
- `main.py` запускает все остальные части приложения
- `debug_email.py` - проверка работы почты
- `email_sender.py` - модуль отправки писем на электронную почту
- `generator.py` - создаёт код подтверждения

### Тесты
Все тесты выполняются из файла `tests.py`, который использует библиотеку `unittest`.
